      Local tables: Prefix with # (e.g., #MyTemp)

      Local tables are created as SQL Server temp tables. Table names are automatically sanitized (spaces become underscores). In SQL queries, reference them with the # prefix. Example: SELECT * FROM Room_schedule rs JOIN #My_Temp t ON rs.Room_Id = t.RoomId.

      Remember: Always use #TableName in your SQL queries when referencing a local table.
